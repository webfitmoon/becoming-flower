# 비커밍

HTML·CSS·JavaScript로 만든 꽃 선물 랜딩페이지입니다. 외부 라이브러리나 빌드 과정 없이 `index.html`을 열어 확인할 수 있습니다.

## Vercel

1. GitHub 저장소를 Import합니다.
2. Framework Preset은 **Other**, Root Directory는 저장소 루트를 사용합니다.
3. Build Command는 비워 두고 Output Directory는 `.`을 사용합니다. 환경 변수는 필요하지 않습니다.
4. Deploy를 실행합니다.

## 포함 파일

- `index.html`, `styles.css`, `reference.css`, `script.js`
- `graduation-popup.css`, `graduation-popup.js`
- `assets/`의 사용 이미지 및 Pretendard 폰트·라이선스
- `vercel.json`, `.vercelignore`

이미지는 예시 자료이며 실제 고객·상품 사례를 의미하지 않습니다. 문의 링크는 현재 페이지 내부 안내로 연결됩니다. 공개 전 실제 문의 채널과 상품·배송 조건을 확인해 주세요.
